# Senior Capstone - Project Egress
<img width="480" height="360" alt="ProjectEgressLogo" src="https://github.com/user-attachments/assets/ffc427d9-ccd7-4696-8853-1d071e71673a" /><br>
This repository is for "Project Egress", a video game for submission as a senior capstone project. <br>
The game is a 2D platformer inspired by Portal and Splatoon.<br>
The game will feature gameplay elements such as paint tools, paints, and a variety of traps to damage the player. <br>
Paint tools and paint types will add a unique twist to the platforming by providing different abilities for the player to interact with!<br>
